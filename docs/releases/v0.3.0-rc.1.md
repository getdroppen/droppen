## What's new in v0.3.0-rc.1

A test release. A prerelease carries no desktop app and never moves `latest`.

This adds **A2A**: another agent — dont-do first — can hand this computer a task, follow the session it runs, answer its questions and take the result back. The A2A server runs on the computer itself; a small container, `ghcr.io/getdroppen/droppen-a2a-proxy:v0.3.0-rc.1`, carries a cloud client's calls to it through a relay. Entries (directory, provider, permission mode, a worktree per task), tokens and the proxy live under Settings → A2A and My devices.

An A2A proxy is a new kind of device in the account chain, with a flag of its own. A computer or desktop app from before this version stops at the entry that adds one, so **upgrade every computer that runs AI, and the desktop app, before adding a proxy**. Removing a proxy, or stopping a computer from running AI, renews the identity keys of the computers it could reach, as losing a device of yours does.

## v0.3.0-rc.1 的新内容

一个测试版本。预发布不带桌面 App，也不移动 `latest`。

这一版加入 **A2A**：另一个 agent（第一个是 dont-do）可以把任务交给这台电脑，跟进它开的会话，回答它的提问，并把结果取回去。A2A 服务跑在电脑本机；一个小容器 `ghcr.io/getdroppen/droppen-a2a-proxy:v0.3.0-rc.1` 经中继把云端调用送到它。入口（目录、provider、权限模式、每个任务一张 worktree）、token 和代理都在「设置 → A2A」与「我的设备」里。

A2A 代理是账号链上一种新的设备，带自己的标志位。旧版本的电脑和桌面 App 会停在加它的那一条上，所以**在添加代理之前，先把所有运行 AI 的电脑和桌面 App 都升级**。移除代理、或让某台电脑停止运行 AI，会像失去一台你的设备一样，让它够得到的电脑轮换身份钥。
