## Droppen App for macOS

`Droppen-0.2.131.dmg` — the desktop app (Apple silicon and Intel), signed with Developer ID and notarised by Apple. It needs macOS 13 or later. Open the DMG, drag Droppen to Applications, open it.

Droppen 0.2.127, 0.2.128, 0.2.129 and 0.2.130 update themselves to this release: they download it in the background and install it the next time you quit, or at once with *Restart to Update*. Droppen 0.2.125 and 0.2.126 update themselves in two steps: first to 0.2.127, which https://github.com/getdroppen/releases (where they look for updates, now archived) still offers, then from 0.2.127 to this release. Version 0.2.124 and older do not update themselves: download this DMG once and replace the app in Applications.

## macOS 版 Droppen App

`Droppen-0.2.131.dmg` 是桌面 App（Apple 芯片和 Intel 芯片的 Mac 都能用），使用 Developer ID 签名并经过 Apple 公证，需要 macOS 13 或更高版本。打开 DMG，把 Droppen 拖到「应用程序」，然后打开它。

0.2.127、0.2.128、0.2.129 和 0.2.130 会自动更新到这个版本：在后台下载，并在你下次退出时安装；也可以用「重启以更新」立即安装。0.2.125 和 0.2.126 会分两步自动更新：先更新到 0.2.127（它们检查更新的 https://github.com/getdroppen/releases 已归档，但仍提供 0.2.127），再从 0.2.127 更新到这个版本。0.2.124 及更早的版本不会自动更新：请手动下载一次这个 DMG，替换「应用程序」里的 Droppen。


## What's new in v0.2.131

### Signing up

- **When droppen.app's sign-up is closed, its pages say so.** The public pages follow the Hub's sign-up mode (v0.2.130). When sign-up is closed, the home, download and pricing pages now say "Sign-up is closed for now" and offer the waitlist, for Free or for Pro, instead of the invite wording: you are e-mailed when sign-up opens, or when Pro does. Open and invite-only sign-up look as in v0.2.130, and droppen.app's sign-up is open.
- If the sign-up form could not find out how sign-up works and droppen.app then asks for an invite code, the form asks again, so the invite code field shows as required rather than "(optional)".
- The privacy notice's waitlist section says that it keeps the plan you are waiting for, and that your address is used only to e-mail you an invite, or to tell you when sign-up or Pro opens.
- **New accounts start on the current device list format only.** Every app since 0.2.125 creates them so. droppen.app now refuses to create an account on the older format, which only a page or app from before 0.2.125 would do, and tells it to reload or update. Accounts made on the older format carry on as before.

### Installing

- **droppen.app/install.sh is the installer itself, not a redirect.** droppen.app now serves the `install.sh` of the release it was built from, byte for byte that release's file, where it used to redirect to the latest release's file on GitHub. Its sha256 is `install_sh` in `https://droppen.app/.well-known/droppen-build`. It installs the latest release (or `DROPPEN_VERSION`) as before.
- The release page's list of files now names `SHA256SUMS-server` and `SHA256SUMS-server.sig`: the checksums `install.sh` goes by, and their signature by the release key it pins. Every release since v0.2.130 has both.

### The local server

- **A page that stops reading no longer holds up the local server.** The live feeds of a session and of the session list now give up a connection when a message to it has not gone out within 90 seconds, as when a phone loses its network in the middle of a long history, and close it within 2 seconds. Before, such a connection could stay attached for good, and a restart or upgrade of the server waited for it. A page that is reading is not affected.

## v0.2.131 更新内容

### 注册

- **droppen.app 暂停注册时，页面会如实说明。** 公开页面跟随 Hub 的注册方式（v0.2.130 起）。暂停注册时，首页、下载页和价格页现在会写「目前暂停注册」，并提供免费版或 Pro 的等候名单，而不再显示邀请的说法：开放注册或 Pro 开卖时，我们会发邮件通知你。开放注册和仅限邀请注册时的页面与 v0.2.130 相同；droppen.app 目前开放注册。
- 如果注册表单没能得知注册方式，而 droppen.app 随后要求邀请码，表单会再问一次，这样邀请码一栏会标为必填，而不是「（可选）」。
- 隐私说明里关于等候名单的一节写明：会保存你在等的方案；你的邮箱只用来给你发邀请，或在开放注册、Pro 开放时通知你。
- **新账户只使用当前的设备列表格式。** 0.2.125 以来的每个版本都这样创建账户。droppen.app 现在拒绝用旧格式创建账户（只有 0.2.125 之前的页面或 App 才会这样做），并提示它刷新或更新。用旧格式创建的账户照常使用。

### 安装

- **droppen.app/install.sh 就是安装脚本本身，而不是跳转。** droppen.app 现在直接提供它所构建自的那个版本的 `install.sh`，与那个版本的文件逐字节一致；以前它跳转到 GitHub 上最新版本的文件。它的 sha256 是 `https://droppen.app/.well-known/droppen-build` 里的 `install_sh`。它和以前一样安装最新版本（或 `DROPPEN_VERSION` 指定的版本）。
- 发布页的文件列表现在列出了 `SHA256SUMS-server` 和 `SHA256SUMS-server.sig`：`install.sh` 所依据的校验和，以及它所固定的发布密钥对校验和的签名。v0.2.130 以来的每个版本都有这两个文件。

### 本地服务端

- **停止读取的页面不会再拖住本地服务端。** 会话和会话列表的实时推送，现在如果一条消息 90 秒内还发不出去（比如手机在加载很长的历史时断了网），就会放弃这个连接，并在 2 秒内关闭它。以前这样的连接可能一直挂着，服务端重启或升级时也要等它。正常读取的页面不受影响。
